# 变更记录

## 1.0.2-r1 — 2026-10-24

- 启动前 90 秒缩短依赖重试间隔；健康探测后台执行，接管后立即验证出口，恢复期快速重试。
- SSR/PassWall 配置事件和内容修订检测唤醒出口验证；SOCKS 节点变化不重启 FlowDNS，透明模式保持节点配置验证后重载。
- 国外出口状态绑定核心 PID 和节点配置修订，丢弃变更前的过期探测；监听和出口验证分开显示。
- 恢复期首次失败即可验证加密备用 DNS，稳态仍要求连续失败；只有备用成功才切换，主 DNS 切回保留滞回。
- 后台健康检查占锁时，手动任务可排队等待；保留内核锁，避免错误清锁和隐式重载竞争。
- LuCI v2 资源路径避免升级缓存混用；增加并发任务、同时间戳节点内容变化和恢复状态回归。
- 发布 MTK cortex-a53 / RK3568 generic 两套服务包和通用界面，保留已有核心与配置；验收范围见本次部署记录。

## 1.0.1-r1 — 2026-10-23

- 增加可选私有 sing-box 1.12.25 核心，FlowDNS 环境优先使用，保留系统核心供其它插件使用。
- 移除未使用的 nft socket 模块依赖，保留实际 TProxy 配置检查。
- aarch64_generic 用户态编译与 R5S 安装烟测；不自动替换 SmartDNS/SSR 接管。
- 三包校验与包含 vendored 上游源码的交付支持，具体边界见 RELEASE-1.0.1.md。

## 1.0.0-r1 — 2026-10-23

- 固定0.4.0数据路径；两种模式保留，升级保持原配置/模式。
- 正式LuCI资源v1，透明模式名称明确SSR Plus/Xray边界。
- 发布检查核对双包/源码版本，并按control架构检查私有DNS ELF，移除仅ARM64假设。
- GPL授权文本随源码与服务安装；新增安装升级、开发复盘、排障、移植和发行归档工具。
- 修复本地HTTPS测试服务器在accept线程串行TLS握手的覆盖缺口，增加慢握手负对照；并发数量/超时不放宽。
- 当前目标为ARM64实机；其它平台需重编和验收。

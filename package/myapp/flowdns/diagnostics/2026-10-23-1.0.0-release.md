# 2026-10-23 FlowDNS 1.0.0 正式发布验收

## 用户反馈与发布范围

0.4.0透明模式用户截图：YouTube connection speed 21,998→42,967Kbps，buffer health 37.65→75.83秒，1080p30；用户报告首页从约10秒变为立即加载。随后用户测试SOCKS，报告速度与透明模式相近，授权冻结正式版、上传安装、归档开发过程/排障及准备移植。用户反馈不冒充受控全线路性能结论。

安装前只读基线：当前0.4.0-r1、SOCKS模式、ready、自启动已注册。1.0.0保持当前模式和已有配置，不主动切换为透明模式。

## 本版变更

不改变0.4.0转发和DNS事务算法；版本/资源v1、正式模式名称、双组件授权、目标架构ELF/版本发布校验、开发/移植/排障/安装材料及干净源码归档。服务包含原生私有DNS2.93，跨架构仍需目标编译和真机验收。

### 临时测试子网暴露的边界

首次隔离DNS连接超时，但生产ready与health均正常。无连接UDP客户端recvfrom确认：向桥主地址192.168.10.1:53查询，应答从临时子网地址10.253.254.1:16553发出，没有匹配反向NAT元组；真实主LAN仍有正常业务。只给专用测试子网路由指定桥主地址为首选源后，SOCKS/透明/恢复SOCKS全部DNS和HTTPS通过。正式代码未增加多地址通配应答适配，这种桥上多个IPv4/跨子网情况必须列入新平台验收，不能由当前单主LAN结果宣称普适。该临时路由与附加地址已清理。

### 最终状态和边界

已恢复升级前的完整FlowDNS配置，逐字节核对FlowDNS、SSR、DHCP、SmartDNS配置均与备份相同。正式状态version=1.0.0、mode=socks、active_mode=socks、running/dns_ready/attached/health_ok/autostart均true。实际新v1资源与双许可证存在，旧v04资源移除。临时netns/veth/子网/路由均删除，超时恢复守护已解除并退出；旧包和手动恢复脚本保留在上述私有目录。

本轮未重启路由器，未做高UDP流量/最大吞吐压力、断电冷启动、一天以上稳定性、真实公网IPv6或其它架构真机测试。当前版本定版不扩大此前验证边界。源码归档只含包源码/文档/测试/授权/固定dnsmasq上游源码，不包含私有备份与节点凭据。

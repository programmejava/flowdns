## 0.3 实验透明核心模式

保持原模式默认值不变。新增真实 IP DNS 前端、国内内核旁路、SSR 生成器衍生的独立 Xray TProxy、三进程监管与所有配置文件整体快照/回退。候选 sing-box/Xray/dnsmasq/nft 配置均在停止当前服务前校验。不支持的节点或缺少 nftset 不应影响旧核心；切回原模式会清空新模式运行配置。

本机测试需覆盖实际生成器、VLESS/Reality 配置检查、双栈 LAN DNS 学习集合、国内 TCP/UDP 源地址保持、国外 TCP/UDP 经 Xray、SOCKS 仅用于 DNS、手动规则、旧 Fake-IP 拒绝和任一子进程失败后的清理。真实节点性能和目标路由器验收仍未完成，不能由本机转发正确推断速度提升。

## 0.3.1-r1 本地修复

用户授权修复，远程路由器继续停用 FlowDNS。私有打包上游 dnsmasq 2.93（DNS/nftset，无 DHCP/TFTP/脚本），不修改系统 dnsmasq 包。正式 TCP fork 与 UDP 同时更新集合的对照中，旧 2.90 复现 netlink cache initialization resource busy，新 2.93 通过；测试仅清空 user/group 绕过命名空间 setgroups 限制，不再使用 --no-daemon。

移除 UCI commit 隐式 procd reload trigger；reload_service 和 LAN up 均通过后台任务队列，不直接替换 prepared/recovery 实例。真实 rc.common 加 procd adapter 验证忙时 reload 不提交 boot 实例，旧 init 对照失败；该测试不等于真实目标 procd 并发已验收。实际内核锁回归验证占用操作可见、busy boot 不覆盖原始 DNS 错误。恢复日志保留 DNS/Xray 错误尾部。

新增原 VLESS 与 Reality/Vision 两轮混合并发，每轮 128 次双栈 TCP/UDP DNS、实际子进程验证、集合写入和后续 Xray 业务。完整回归和最终包检查结果以本轮日志为准；目标仍需有本地恢复条件的维护窗口，未自动安装或启动远程服务。

## 0.3.1-r2 真机冲突修复

真实包跟踪确认 SSR 主透明代理设为 nil 并重启后，旧 `inet ss_spec` 表仍在 dstnat 将 Google/YouTube 443 重定向到已停用的 1234，覆盖 FlowDNS TProxy 的目的地址；旧 `ip ss_spec_mangle` 还残留 UDP 接管/丢弃规则。原检测只覆盖 SSR- / SSR_ / PSW / PassWall 字样，漏掉 ss_spec。本次统一大小写并识别 ss_spec，保留外部规则不自动清除，在准备或停止当前服务前明确拒绝应用。真实 RPC 运行回归验证两种原生表及旧大写标记均拦截、普通 fw4/FlowDNS 规则仍可完成 apply。服务包升为 0.3.1-r2，界面接口未改动。

## 0.4.0 两项高优先级改进

QUIC策略在所选代理出站识别后解析，Vision默认拒绝时在nft代理链提前拒绝UDP443，保持国内直连/其它UDP。显式允许只在克隆的客户端出站中增加Vision UDP443后缀，不修改SSR原配置。

DNS-only分类要求透明模式、非DNS政策字段不变、Xray结构和前端/nft文本一致；不匹配仍完整重载。请求通过工作锁与引擎PID绑定；引擎独立替换DNS子进程，保持前端/Xray，验证应答后提交运行政策，失败恢复原DNS，回退后重置健康选择冷却以避免每5秒重试。事务结果独立记录与限长日志供诊断。外层监管识别DNS-only结果后继续原组，不执行detach或整组重启。

完整隔离回归通过，包括原模式、真实Reality/Vision、双栈QUIC允许/拒绝边界、128次正式并发DNS、同一TCP长连接跨DNS更新与有效配置运行绑定失败回退、PID与nft元素保持。目标安装与真机验收单独记录。
